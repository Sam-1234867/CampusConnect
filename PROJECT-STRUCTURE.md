# CampusConnect Project Structure

```text
src/
├── components/
├── pages/
├── context/
├── services/
├── styles/
├── App.jsx
└── main.jsx
```

## Main Folders

* **components** — Reusable components
* **pages** — Application pages
* **context** — Shared application data
* **services** — Firebase and data services
* **styles** — CSS files
